Gap between interleaved knots

Freakinsweetapps shows a blank strip between knot rows — helps visually separate where one knot ends and the next begins. How large should it be?

A

Half bightDist (Recommended)

Gap = bightDist / 2 = one cellSize. Matches the visual weight of freakinsweetapps — enough separation to see the boundary without wasting space. Total canvas height = numStrands × heightPerStrand + (numStrands - 1) × gapHeight.

B

Full strandWidth

Gap = strandWidth. Proportional to strand thickness — thicker strands get bigger gaps. Slightly more space than A.

C

Configurable prop with default

Add a knotGap prop to UnrolledMandrelDiagram (default = bightDist / 2). Caller controls it explicitly.
