Column width for multiple interleaved knots

When N knots share the same mandrel, strands from different knots alternate pins. A strand run between pins needs horizontal space proportional to N. How should innerWidth scale?

A

Multiply columns by numStrands (Recommended)

innerWidth = strandParts × cellSize × numStrands. Each column slot expands to fit all interleaved strands. Geometry (partDist, angle, dx, dy) recalculated from new width. Matches freakinsweetapps behaviour exactly.

Pros

  • Correct for any N
  • Single knot (N=1) unchanged
  • Consistent with reference implementation

Cons

  • Canvas gets wider with more knots
B

Keep width fixed, shrink cellSize by 1/numStrands

Same canvas width regardless of knot count — compress each cell to fit. cellSize = baseCell / numStrands. Strands get thinner as more knots added.

Pros

  • Predictable canvas size

Cons

  • Strands become unreadably thin at N≥3
  • Doesn't match reference
