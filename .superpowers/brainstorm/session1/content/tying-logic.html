Implementation Approach Selection

A

Cumulative Path Plotting

Plot the strand's full sequence of runs as a continuous 2D path. When it crosses a boundary, it physically moves into the "Extra" blocks. We then render these paths in all 3 blocks (mirrored) so the "active window" always shows the full crossing logic.

B

Static Grid with Jump-Backs

Plot only within the window and use visual "jump-back" lines to show where the strand reconnects. (Less elegant for a tying guide).
